
# StageReady

A full-stack repertoire, practice, and setlist management platform for musicians.

## Problem Statement

Musicians need a centralized way to organize their repertoire, track practice progress, and prepare for live performances.

StageReady provides a single platform to manage these activities efficiently.

## Project Objectives

- Help musicians organize their repertoire.
- Track individual song readiness.
- Build setlists based on performance duration.
- Monitor practice habits and progress.

## Functional Requirements

### Repertoire Management

- Add, edit, and delete songs.
- Search and filter songs.
- Store song title, artist, key, duration, tuning, and capo position.
- Track song readiness using predefined statuses.

### Setlist Management

- Create and save multiple setlists.
- Add and remove songs from setlists.
- Reorder songs.
- Calculate total performance duration.
- Generate 30, 60, or 120-minute setlists.

### Practice Tracking

- Record practice sessions.
- Track practice duration.
- Update song readiness.
- View practice history.

### Dashboard

- Display total songs.
- Display performance-ready songs.
- Display total repertoire duration.
- Display practice statistics.

## Nonfunctional Requirements

- Responsive design for desktop and mobile.
- Secure authentication and authorization.
- Input validation and error handling.
- Persistent database storage.
- Automated testing.
- Accessible user interface.
